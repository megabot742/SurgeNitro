# SurgeNitro
Car Racing Games

# Installation guide
1. Clone repository
2. Download resources from Google Drive Link: https://drive.google.com/file/d/1xNgC1---VFvmIoN-n69BxXiIGsbOZJ6z/view?usp=sharing
2. Make sure to place the extracted file in the right folder Assets for Unity to identify.
3. Open the project in Unity and start working!

# Note
- Unity 6 Version: 6000.0.60f1
- If the link expires, contact phuocloc742@gmail.com to update
